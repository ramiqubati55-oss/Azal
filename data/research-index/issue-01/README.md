# Azal University for Human Development (AUHD) — Institutional Research and Academic Works Index, Issue 01

## Dataset summary
This package contains a bibliographic index of 725 research and academic-work records assembled for review and discoverability. It is **an index, not the full texts of the listed works**.

- Total records: 725
- Original group labels: 656 `الأساسي` (base) and 69 `المضافة` (added)
- DOI URL populated: 654 records
- Number of subject/field category labels: 23
- Work types include 544 book chapters, 84 scientific articles (`مقال علمي`), 40 graduation projects (`مشروع تخرج`), 20 student reviews (`مراجعة طلابية`) and other types.
- Most records have no authors entered in the source dataset (only one populated `المؤلفون` value).

## Scope and interpretation
**These are catalogued records, not 725 independently verified, peer-reviewed AUHD-affiliated articles.** Entries include published articles, book chapters, graduation projects, reviews, corrections and other records. Neither institutional affiliation, the author identities, nor publisher record accuracy has been comprehensively verified in this index. The presence of a DOI URL does not confirm affiliation or peer-review status.

This dataset should be described as a **preliminary institutional bibliographic index**. Use the DOI and source links to verify each record prior to attributing it to AUHD or presenting it as an approved research output.

## File content
`AUHD_Research_Index_Issue_01_725_Records.csv` — UTF-8 CSV containing the following Arabic field names in their original order:

1. رقم السجل — local record identifier
2. العنوان — work title
3. القسم / المجال — department/subject category
4. سنة النشر — publication year
5. نوع العمل — work type
6. المصدر — journal, book or other reported source
7. المؤلفون — authors, often blank
8. المشرف — supervisor, often blank
9. الطلاب — students, often blank
10. عدد الصفحات — page count, often blank
11. لغة البحث — language, often blank
12. رابط DOI — DOI URL, when available
13. رابط الناشر أو المصدر — publisher/source URL, when available
14. رابط النسخة المفتوحة — open-access copy URL, when available
15. المجموعة — collection subset label

All fields in the CSV are preserved unchanged from the submitted file. Empty cells mean that data was not supplied; they should not be interpreted as evidence that a property does not exist.

## Important limitations
- No row-level author-affiliation verification has been carried out here.
- Some types are not research articles; do not aggregate this file as an article-only performance indicator.
- DOI identifiers are listed as provided; their resolution and exact metadata have not been cross-checked for every row.
- Please check rights and permissions before republishing any source texts; this deposit contains metadata, not source PDFs.
