# AUHD — international metadata deposit preparation (Issue 01)

This directory contains a machine-readable export of 725 source-preserved bibliographic/academic records reviewed by the university representative (confirmed 13 November 2026). It includes 654 DOI links, 73 publisher/source links and three possible open-copy references. The source CSV is unchanged at `data/research-index/issue-01/AUHD_Research_Index_Issue_01_725_Records.csv`.

- `records.jsonl`: 725 entries with source fields and explicit review provenance, without inferred authors, affiliation details or reuse licenses.
- `manifest.json`: institutional ROR, deposit description, quality metrics and current registration status.

**Scope:** an institutional bibliographic index. It is not equivalent to 725 AUHD-authored peer-reviewed papers or an AUHD-hosted open full-text repository. The user's confirmation establishes a claim of institutional catalog review; underlying reviewer evidence is not in this CSV.

**Next action:** upload the original CSV and structured metadata as one dataset to an authorized AUHD collection in Harvard Dataverse or a Zenodo community; verify the institutional right to select the metadata dataset license before publishing. The Harvard Dataverse collection is https://dataverse.harvard.edu/dataverse/auhd-research . An earlier draft DOI 10.7910/DVN/WU0FVP was user-reported, **not confirmed as published**.
