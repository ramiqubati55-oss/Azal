حواجز الجودة التي يجب إزالتها

  • 724 سجلًا يفتقر إلى أسماء المؤلفين؛ لا يمكن ربط هذه السجلات بأعضاء هيئة التدريس بثقة.
  • وجود DOI أو صفحة ناشر لا يُثبت الانتساب لجامعة آزال أو السماح بإعادة النشر.
  • رابط النسخة المفتوحة لا يساوي امتلاك إذن للإيداع أو إعادة استضافة النص.
  • لا توجد حاليًا واجهة OAI-PMH مستقلة أو عضوية فهرسة معتمدة للبوابة.

الخطوات اللازمة

  1. التحقق من المؤلفين والانتساب وDOI لكل عمل قبل اعتماده علميًا.
  2. تحديد خمس مواد علمية كاملة على الأقل مع موافقة الإيداع ونوع الترخيص وبيانات المصدر.
  3. رفع الملفات المصرّح بها على مستودع مؤسسي يدعم الحصاد الآلي.
  4. اختبار OAI-PMH ثم فحص توافق OpenAIRE، ومتابعة فتح التسجيل لدى OpenDOAR.
